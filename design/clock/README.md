# 伸颈式磁吸检修盖座钟

## Must satisfy
六个独立制造件：底座 base、钟壳 body、一体盘面 dial、磁吸电池盖 battery_cover、左滑轨 rail_left、右滑轨 rail_right。盘面、原图数字及60个刻度保持布尔融合的一个连续实体，不能单独移动；字形轮廓与浮雕布局不修改。钟壳直径240 mm、厚32 mm、背板厚5.6 mm、后仰16°，后缘R7、前缘R1、内口R0.8；盘面外唇R1、背缘R0.5。伸颈端部仍直角收头，根部圆滑内凹；底座宽90 mm、高160 mm，收纳底离底35 mm、收纳深125 mm。底脚前伸量28 mm，比原先增加18 mm，落地外形约90×110 mm，总包络90×117.96×160 mm；下斜面平顺接入原颈根内凹，颈端直角保留。
slide_mount：钟体从上向下滑入底座双T槽。两条钟背滑轨分别制造、分别粘合，背板仅保留0.1 mm深浅定位槽。每条粘接底板宽10 mm、厚0.85 mm，进入浅槽0.05 mm，槽底胶层空间0.05 mm；浅定位槽单侧间隙0.1 mm。浅槽下端按滑轨粘接底板R2圆角作0.1 mm外偏置，对应R2.1圆角，圆心重合而不是矩形尖角。滑轨在背板平面处长38.6776 mm，从钟心下方47 mm延伸到下方8.3224 mm；其上端按底座水平顶面斜切，装到底后整个顶面齐平。T形滑动配合主面单侧0.25 mm，满足用户至少0.1 mm；底部止挡为设计接触。左右两条滑轨采用完全相同的普通T形结构，不再含单边弹臂、切缝或止退凸点；底座对应凹坑取消。两侧宽脚槽的下端改为R2.25圆角、配套轨脚下角R2，脚端轴向预留0.25 mm，使槽口外侧下端连续封闭，同时保留底座原R18圆角轮廓。两侧槽口至外侧平面及下部圆角的实际最小壁厚均须至少2 mm；底座加宽到90 mm，中央连接面保持连续平面，取消原方形让位凹陷。
battery_hatch：盖板主体位于钟背中心，58×58 mm、R3，厚2.2 mm，四周间隙0.3 mm。磁吸盖与表壳上缘中央各留一个磁铁位，圆心(0,23) mm，共需2颗Ø7×1 mm磁铁；孔径7.26 mm、深1.26 mm，直径及深度分别在原孔尺寸上增加0.16 mm。壳体外侧下缘取消半圆凹陷，盖子下缘改15×2 mm长方形扣手槽；2 mm与原半圆向盖内切入的高度一致，15 mm为三个原标称直径5 mm半圆的宽度。磁铁座连接到开口上缘，其内侧Z=5.6 mm与加厚背板的内部平面齐平，无向机芯腔凸起的台阶；最小机芯腔净深20.4 mm，大于用户要求17 mm。
wall_hanger：保留钟背居中上方钥匙孔，入口中心高于钟心86 mm，入口Ø9 mm、上窄颈3.8 mm、窄颈上升10 mm，按用户图片的下宽入口和上窄颈轮廓制作。内侧周围设16×26 mm、R3圆角矩形下凹，中心Y=89.7 mm，从背板内面Z=5.6 mm下凹至Z=2.8 mm，深度和剩余底厚均为实际背板厚度的一半。
dial_nest：环形盘面承托顶面保持Z=25.8 mm、内半径112 mm及原盘面位置；承托环自背板Z=5.6 mm延伸至顶面，完整填实下方环区，取消悬空的薄台阶。原壳底周边加强过渡保留。
盘面磁吸固定：盘面背面12/3/6/9点及钟壳对应四位各设Ø7.1×深1.1 mm盲孔，孔心半径111 mm，共四对Ø7×1 mm磁铁8颗；连同电池盖一对总计10颗。四个钟壳承托座与壳体融合，周边默认2 mm留料，从背板连续支撑到Z=25.8 mm。盘面孔朝钟背开口，盘面基准背面Z=26 mm、孔底Z=27.1 mm，最薄平区计算前方仍留至少1.3 mm。钟壳四孔口Z=25.8 mm、孔底Z=24.7 mm，孔轴与盘面四孔逐一共线；避开上方挂孔凹位，中心机芯空间保留。电池盖原有磁铁孔仍为Ø7.26×深1.26 mm。
展示位置按用户要求：底座单独放在钟体右侧，在当前设计模型内沿Z方向竖直立放，底面Z=0；钟壳与表盘原位置和角度不变。此为展开摆放，滑轨仍粘合在钟背定位位置；装配尺寸按原入座位置验证，不能按右侧展示位置判断滑槽配合。

## Making and assembly
默认黄色PETG / FDM。保留12个8×4 mm小时标记、48个6×0.9 mm分钟标记，中心半径101 mm；1–12数字按用户参考图轮廓，名义字高25 mm、中心半径77 mm，凸起0.6 mm。盘面为单一连续实体，白色默认打印后对浮雕上表面及侧面涂装，或用兼容切片器的表面分色；不能直接把2.4 mm以上整层改白，因为上翘外缘与浮雕高度接近。盘面背面朝下打印，直径234 mm，机器需足够幅面。
指针下表面应距平盘面至少1.1 mm，留0.5 mm浮雕上方间隙。轴总长14 mm不能证明螺纹段、针孔和实际指针高度；使用原配垫圈螺母，实物安装后手转整圈。最长针按用户90 mm，216 mm平区也兼容图片另标102 mm的分针。机芯参考56×56×17 mm类别，参考 https://www.m-p.co.uk/muk/parts/movements-quartz.htm ，采购按用户14 mm轴长；未取得具体机芯STEP，不建代用实体。中央安装孔沿用Ø10 mm。
底座底面朝下打印，侧后壁名义3 mm、侧边R18、口沿R0.8；伸颈下方悬垂处从底板加支撑，保护滑动面与直角收头。去除滑槽毛刺后试配，勿把贴合端磨成圆头。收纳孔底面35 mm为用户横线的估算可调值。底座后侧底部内收8 mm。
钟壳可背面朝下、盘面台阶朝上，但0.1 mm定位浅槽浅于常见0.2 mm层高，需采用不大于0.1 mm的对应层高或使定位面朝上，以免被首层和象脚吞掉。R7后缘初始悬垂、内部磁铁座与盲孔需在切片时检查支撑及桥接。环形盘面台阶下方已填实，无环形悬空底面；挂钉孔凹位朝腔内开口，注意凹位底部2.8 mm留料。保护盘面台阶及磁铁位。
盖子外平面朝下、磁铁孔向上打印，不需要铰链支撑。盖子磁铁孔的底部保留0.94 mm塑料；钟壳磁铁位底部保留1.84 mm材料。局部盲孔底板仍完整封闭；盖厚及壳背厚度保持2.2 mm及5.6 mm。磁铁与孔径单边胶隙0.13 mm、深度胶隙0.26 mm；粘前先试配并确认这一对磁铁的相吸极性，勿把相斥方向粘死。胶水由用户按PETG和磁铁表面选定，避免溢胶堵住盖周间隙。
两根滑轨以平整粘接面落地、T形头朝上，左右结构相同，可互换；没有弹臂、细缝或止退小凸点。清理功能面毛刺，保护下端轨脚R2和顶部斜面。先用短滑槽试片校准打印收缩，再打印完整件；不要以CAD间隙代替实物试配。
清理钟背0.1 mm定位浅槽，将左右轨分别干装定位，两条轨均保持斜切上端朝上。先试滑底座确认顶部齐平，再拆下底座，按胶种要求处理表面并粘轨，保持定位直到固化。0.05 mm胶床是几何预留，实际用胶量取决于胶种。轨与壳体必须保留为分体件，禁止实体融合。
从正面安装机芯与盘面，机芯使用原配轴螺母和垫圈。先干装四对盘面磁铁并检查相对极性，再分别粘入盘面背面与钟壳四孔；每孔按Ø7×1 mm磁铁留单侧0.05 mm胶隙和0.1 mm深度胶隙。盘面采用四对磁铁定位吸合，替代原默认胶点固定；磁铁坐到底时每对两磁铁表面名义间距0.4 mm，实际吸力取决于磁铁等级、胶床和实物打印，尚未实测。原嵌套间隙为单侧径向0.3 mm、轴向0.2 mm。磁铁安装后将磁吸盖放入中央定位台阶。钟体沿底座双槽向下滑入至止挡，顶部齐平、底部止挡定位。
换电池先扶稳底座并向上滑出钟体，再从盖下缘长方形缺口扣开磁吸盖；换好后吸回盖子并重新滑入。用户明确无需为翻盖与底座另做避让。挂墙前取下底座，选择钉帽能进入Ø9入口且大于3.8 mm颈部、钉杆能进入窄颈的钉子；墙面、钉子及磁吸力未实物测定。

## Inspection
盘面四孔及钟壳对应承托座的共享半径参数已由112.5 mm减为111 mm，径向同步内移1.5 mm。已观察盘面背面和钟壳内侧顶视，四位仍逐一对应；盘面/壳体配合精确检查无体积重叠，间隙0.2 mm，左右滑轨与壳体检查也通过。孔径和孔深参数维持7.1 mm和1.1 mm。
已观察盘面背面四孔及钟壳内侧四个一体承托座的顶视与斜视；孔分别位于12/3/6/9点。盘面及钟壳代表孔分别实测Ø7.1 mm、深1.1 mm，用户尺寸期望校核通过；对应3点位孔轴坐标均为X=111、Y=0，四位共用同一中心坐标列表。盘面仍为一个有效实体，60刻度和原图数字保持融合；盘面与钟壳无体积干涉，最小间隙0.2 mm。左右轨和电池盖与壳体的逐对检查均无体积干涉。
磁铁孔口圆弧实测直径7.26 mm、孔口至孔底沿轴向实测1.26 mm，两项均通过用户0.16 mm增量后的期望校核。表壳/电池盖、表壳/盘面及表壳/左右滑轨分别检查无体积重叠，间隙依次为0.3 mm、0.2 mm及两侧各0.05 mm。
已观察钟壳腔内斜视及顶视：台阶下方完整填实，挂孔周围圆角矩形凹位可见。背板完整厚度5.6 mm实测通过；凹位圆角为R3，圆柱侧面Z=2.8至5.6 mm。凹位深度及其底部到外侧背面的剩余厚度分别实测2.8 mm，均通过用户一半厚度要求校核。盘面与表壳0.2 mm、盖与壳0.3 mm、左右轨胶床各0.05 mm配合检查通过。
背板外表面与包含磁铁座的连续内部平面，沿Z轴实测5.6 mm且通过期望校核；磁铁座最高Z与背板内面相等的断言通过。浅定位槽两侧下端边均采用R2.1真圆角，与R2滑轨底板同心并留0.1 mm间隙。已观察磁铁座内侧齐平视图、底座前伸后的右视及正视；底座落地Z=0保持不变。壳体/左轨与壳体/右轨分别精确通过无体积重叠检查，胶床各0.05 mm，源内整轨局部裁剪校核也通过；壳体与盘面、电池盖和左右滑轨的分别配对检查通过；全局检测可能在复杂近距面处达到时间上限，不能将未决配对解读为相交。
已对两侧槽切除体到实际外侧平面和R18下角圆柱面的最短距离分别校核，均通过≥2 mm断言，并非仅检查名义侧壁宽度。已观察近距正面和斜视，中央凹陷消除，外形圆角保留。
六个制造件各为一个有效封闭实体。已查看底座左右槽末端的近距离正视与斜视，外侧小开口已封闭、原圆角轮廓保留，槽内局部凹坑已取消。左右轨各17个面、45条边，尺寸及对应面面积相同，源中采用相同构造，仅放置位置不同。盘面浮雕源保持原样，包含60刻度和15个数字字符顶部面共75个浮雕顶部面；圆滑外圈保留最大3°解析曲面分片，不改为多边形。
滑轨上端的两个截面端点均通过坐标变换校核为原装配底座的Z=160 mm水平面；钟背浅槽深0.1 mm；最小机芯净深20.4 mm。展示底座在设计坐标(190,0,0)，旋转(0,0,0)，高度沿Z轴为160 mm；实际底面为Z=0平面，法向(0,0,-1)。钟壳和表盘放置保持不变。
已查看上缘单磁铁位、15×2 mm长方形扣手、无半圆外凹的壳体背面及竖直底座整体预览。盖子磁铁孔圆弧直径实测7.26 mm，用户期望校核通过；孔圆柱面从Z=0.94至Z=2.2，深1.26 mm。表壳与盖子共用孔径和深度参数，表壳孔从Z=2.5至Z=3.76，背面内部保持Z=5.6 mm齐平。盖子孔底厚0.94 mm、壳体磁铁孔底厚1.84 mm，均为局部盲孔留料，不改变底座两侧至少2 mm的壁厚要求。其余13个配对无体积干涉，壳体与两轨分别单独精确复核无体积干涉；盖与壳最小间隙0.3 mm，盘面与壳0.2 mm，左右轨与壳体胶床各0.05 mm。独立轨源内以包住整条滑轨的实际实体裁剪核验无穿插，并在原入座坐标中对滑动截面精确求距，断言均不小于0.1 mm；滑轨斜顶端两端点水平且位于原底座160 mm顶面。未进行实物打印、磁吸力或胶合承载测试。

## Open
Ø7×1 mm磁铁尺寸为用户提供，磁铁等级未指定；模型只建磁铁位，不伪造采购型号或把磁铁并入打印实体。初次机芯安装从正面进行，中央磁吸盖用于日常电池维护。机芯14 mm为总轴长，螺纹与针孔待实物确认。
接口均采用明确的自由实现：slide_mount为两条相同的独立粘合T轨、无局部凹坑的底座双槽和底部止挡；battery_hatch为一对磁铁、上缘居中磁铁座及中央嵌套盖；wall_hanger为钥匙孔；dial_nest为既有台阶配合。没有未处理连接。
CAD内部钟轴为Z、表盘上方为+Y、钟背为-Z。body原放置(0,0,0)、X=16°抵消源内-16°；dial原放置(0,0,26)不变。装配基准下base原放置(0,-162.12426683702384,-44.101976930719864)、X=-74°；展开摆放时base位于(190,0,0)，旋转为零，在设计标签的地面上竖直站立；原装配变换仅作为滑槽配合校核基准。assembly仍保留既有整机参考变换，不用于判断当前展开摆放的地面姿态。盖子位于钟背原点，左/右轨位于(−35/35,−47,0)。body持有共用接口尺寸，base、battery_cover、rail_left、rail_right通过part("body")读取，防止配合尺寸分叉。
