# 局域网进度座挂两用钟

## 功能与外观
电脑上的vibecoding软件由用户编写；时钟通过同一局域网接收进度状态，使用十枚可独立调色的RGB灯显示。参考本次上传图：白底、细红方格、蓝色正向数字与分钟刻度、四个红色整点方块，外圈及底座默认银色涂装。既有机芯、外壳直径、后盖、磁吸盘面、独立双滑轨和伸颈收纳结构保留。

灯在钟心上方，两行五列，关于12–6点中线对称；默认格距7 mm、列距14 mm、行距14 mm，灯心X为−28/−14/0/14/28 mm，Y为31.5/45.5 mm，灯珠开孔与方格内净尺寸一致：默认7 mm格距减0.4 mm线宽，开孔6.6×6.6 mm，内装6.2 mm方形扩散窗，位于格子中心。独立遮光仓防串光，窗与盘面齐平。数字、Makit文字、刻度和装饰图案与表盘为一体凸起0.2 mm，方格凸起0.1 mm；原消息末尾0.1 m按同句毫米尺寸理解为0.1 mm。网格线宽默认加宽到0.4 mm，格距仍7 mm。12、3、6、9点无灯，使用稍大的实心长条刻度，默认4.5×11 mm；十枚进度灯仅在中央上方两排。全部凸起随表盘作为一个封闭实体制造，可在一体凸起表面后处理着色。示意图的金属外观以PETG后处理实现，不改成金属壳，以保留Wi-Fi通路。

## 电子与供电
用户明确要求定制电路板，因此采用Seeed Studio XIAO ESP32C3（seeed/xiao-esp32c3）配专用RGB灯板/供电载板。控制板21×17.8 mm，选用D10/GPIO10发灯数据；ESP32C6同尺寸但其Wi-Fi 6/Thread能力此产品不需要，PCB验收包含可编辑电路、布线、DRC和制造导出。

披露默认：在用户允许的电池或Type-C两种路径中采用5 V Type-C直供，电子部分无锂电池；原机芯继续独立用AA电池，拔下USB不影响走时。供电接口隐藏在钟体与底座结合区，从收纳掏空内侧插接，电缆经底座内部向下，从下方掏空出线口伸出；拔线后才能向上滑出钟体。不得占用或割穿T轨承载面，保留底座至少2 mm槽外壁。

## 局域网接口默认
2.4 GHz Wi-Fi，无云端依赖；本地配置页设置网络和设备标识，局域网HTTP JSON API查询状态、独立设置10灯颜色及亮度。首次入网默认由设备临时热点提供本地配网页，入网后配置及电脑通信均在同一局域网。默认设备自发现使用mDNS；电脑端可以直接配置IP。LED索引上行0–4、下行5–9，均从左到右；空闲灭灯、等待白色、运行黄色、完成绿色、异常红色，颜色和映射可由电脑覆盖。默认亮度上限25%，30秒无更新保留状态并低亮脉冲提示离线。固件、接口说明与电脑可调用的示例请求应配套，电脑应用由用户完成。

## 机械约束
用户已澄清：钟芯轴长 14 mm，最长指针 90 mm。补充图片中分针另标注 102 mm，因此默认采用直径 216 mm 的纯平扫掠区，兼容这两个长度，不改写用户的 90 mm 要求。

根据最新标注图，底座前上部改成向前伸出的脖子，下方根部圆滑内凹并接到展开的底脚；靠钟体的伸颈端部改为直角，不做圆弧收头，底部默认保留20 mm直线段并与贴合面成90°，后侧底部内收 8 mm。底座下半部向前延伸，底脚前伸量默认28 mm（增加18 mm）；底座落地约 90 × 110 mm、高 160 mm，总包络约 90 × 117.96 × 160 mm，侧边 R18、口沿 R0.8。钟体外径 240 mm、后仰 16°、厚 32 mm，后缘 R7 圆角、前缘 R1 圆角、前口内缘 R0.8 圆角；盘面外唇 R1、背缘 R0.5，均为连续圆滑过渡；整机高约 291.93 mm；盘面厚 2.4 mm、边缘翘起 3 mm。这些具体尺寸为可调默认值。

钟体与底座采用隐藏的双T形滑槽卡接，从上往下滑入、向上滑出。钟背两条滑轨为独立制造件，粘合在0.1 mm深的背面浅定位槽内；滑轨加长，装到底后顶面按底座水平顶面的斜度修齐。默认单侧滑动间隙0.25 mm，满足至少0.1 mm。左右滑轨按无弹臂的同一T形结构制造，取消单边弹性止退机构及槽底对应凹坑。底座滑槽下端外缘两侧连续封闭，不留小缺口；两侧槽口至外侧及下部圆角至少2 mm壁厚。默认底座加宽至90 mm，中间大块方形凹陷取消，连接面保持平面。定位浅槽下端按滑轨R2圆角轮廓匹配，浅槽圆角默认R2.1，保留单侧0.1 mm定位间隙；胶层默认0.05 mm，使用用户选定的PETG适用胶。预览中底座在钟体旁边沿设计模型Z方向竖直立放，底面Z=0，表盘和钟壳原位置不变。

后方收纳孔底面按用户横线抬高，默认离底部 35 mm，顶部到孔底的收纳深度为 125 mm；35 mm 为按标注图估算的可调值。

钟芯藏在钟体内部。背面正中心采用58×58 mm、R3圆角正方形磁吸可拆盖，取消铰链和转轴；壳体外侧下缘取消半圆凹陷，盖子下缘改为长方形扣手槽，槽高与原半圆一致、槽长为三个原半圆的长度，具体按15×2 mm实现。表壳和盖子上缘中央各有一个磁铁位，共一对、2颗Ø7×1 mm圆片磁铁；孔径7.1 mm、深1.1 mm，表壳与盖子两孔统一为Ø7.1×深1.1 mm；相对Ø7×1 mm磁铁，径向单侧胶隙0.05 mm、深度余量0.1 mm，壳体及盖子孔底留料分别为2.0 mm和1.1 mm。盖厚2.2 mm、周边间隙0.3 mm。换电池前先向上滑出钟体，再取下盖子，不为底座另做翻盖避让。用户确认机芯腔净深至少17 mm；背板默认加厚到5.6 mm，磁铁座内侧与背板内部平面齐平；裸壳机芯腔20.4 mm，加入遮光件后局部净深19.2 mm；仍高于17 mm要求。上方钥匙孔挂槽保留：默认下入口Ø9 mm、上颈3.8 mm，入口中心高于钟心86 mm；钥匙孔内侧周围设圆角矩形凹位，凹深为背板厚度一半，默认16×26 mm、R3、深2.8 mm，底部剩余2.8 mm。

机芯继续使用用户指定总轴长14 mm的独立AA电池石英机芯，参考外形56×56×17 mm、保留64×64×20.4 mm净腔；新增电子电路不驱动指针。参考外形资料：https://www.m-p.co.uk/muk/parts/movements-quartz.htm 。

验收：底座、钟壳、一体盘面、磁吸电池盖、左滑轨、右滑轨共原六个核心制造件加RGB电子及光学件。盘面图案遵循本次红格蓝字参考图；双轨独立粘合、0.1 mm深定位槽、入座后顶部齐平；滑动配合旷量至少0.1 mm；表壳和盖子都有Ø7×1 mm磁铁位，下缘长方形扣手槽可扣开；机芯腔净深至少17 mm。底座单独在旁边竖直立放、设计底面Z=0，钟壳与盘面位置不变，交付STEP。

壳内环形盘面承托台阶下方沿钟轴方向填实连接到背板，消除悬空环形薄台阶；承托面高度及盘面嵌套位置保留。盘面背面在12、3、6、9点各设直径7.1 mm、深1.1 mm磁铁凹槽，钟壳有四个对应磁铁位；孔中心半径111 mm，盘面孔及壳体对应磁铁座同步向内1.5 mm，避开挂钉孔。钟壳磁铁承托座与壳体一体，周围默认留2 mm材料；盘面孔底按最薄平面厚度计仍留1.3 mm。新增四对Ø7×1 mm磁铁共8颗，连同电池盖一对总共10颗。盘面采用磁吸拆装，替代默认胶点固定；电池盖磁铁孔仍为Ø7.1×深1.1 mm。

整圈外框需呈连续圆形，不得出现可见多边形折角。盘面和表身采用不超过3°的真实相切曲面片细分以约束预览网格，圆弧与尺寸保持不变；这不是增大边缘倒角。

## 内部定位与安装
表盘背面按机芯长56 mm的圆角矩形外形做定位线，默认宽56 mm、R3，线宽0.5 mm、浅刻0.2 mm，以钟轴为中心；不改表盘正面。电路板按现有80×172×1.6 mm主板与22×16×1.6 mm电源小板预留支承和定位，板位为已有电路草案的机械预留，不作为制造版装配模型验证。机芯自带电池及电池槽沿用原结构，中央磁吸后盖保留更换电池的入口；这部分供电不在本次改动范围。电子部分仍按原Type-C直供方案。
